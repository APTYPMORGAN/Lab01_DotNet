## Ответы на вопросы

### 1. Чем `Console.Write()` отличается от `Console.WriteLine()`?

Console.Write() выводит текст в консоль без перехода на новую строку

Console.WriteLine() после вывода текста переходит на следующую строку

### 2. Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?

Возникнет ошибка компиляции, потому что int предназначен для хранения целых чисел, а 3.14 является дробным числом типа double

### 3. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?

Потому что оба числа являются целыми числами типа int. При делении двух int C# выполняет целочисленное деление и отбрасывает дробную часть

### 4. Что означает var в C#? Чем он отличается от динамической типизации в Python?

`var` позволяет компилятору C# самостоятельно определить тип переменной во время компиляции

В Python тип переменной может изменяться во время выполнения программы

### 5. На каких крупных проектах или компаниях используется C# и .NET?

C# и .NET широко используются в крупных компаниях и проектах. Например:

Microsoft — использует C# и .NET для разработки различных программных продуктов и сервисов
Stack Overflow — использует технологии .NET в своей серверной части
Unity — C# является основным языком программирования для разработки игр и приложений в игровом движке Unity
